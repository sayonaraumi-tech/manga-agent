月輪合同会社 業務連動システム PWA試用版 v3（Apple Calendar半手動テスト）

【今回の目的】
PWAとAppleカレンダーの「完全自動ではない連動」をiPhoneで確認する版です。

【手机端】
日程 / 見積履歴 / 帳票 / 保存帳票 の4項目だけを表示します。

【Appleカレンダーへ】
1. 日程を開く
2. 「Appleへ」または「Appleカレンダーへ」を押す
3. .ics ファイルが作成される
4. iPhoneでその .ics を開き、Appleカレンダーへ追加する

帳票を保存して日程タイトルが「請求済」「領収済」等に変わった後、再度Apple用ICSを書き出すと更新後の内容を確認できます。

【制限】
PWAはiPhoneのEventKitへ直接アクセスできないため、既存のAppleカレンダー予定を自動で読み取ったり、同じ予定を直接上書きすることはできません。再インポート時にApple側で重複する可能性があります。この版は操作感の確認用です。

【ICS取込】
Google CalendarまたはMacのAppleカレンダーから書き出した .ics は「日程」から取り込めます。iPhoneのAppleカレンダー単体には標準の全カレンダー書き出し機能がないため、Apple→PWAの自動取込はできません。

【电脑端】
同じURLをPCで開くと、案件・売上入金・支出・銀行照合・月次など完全な后台メニューを表示します。

【保存帳票】
保存済みの見積書・請求書・領収書・小野田請求を一覧表示し、再度開く・PDF再ダウンロードができます。同じ帳票の再ダウンロードでは重複計上しません。

※現在は試用版のため、スマホとPCのデータは各端末ブラウザ内です。Firebase接続後に共有します。
